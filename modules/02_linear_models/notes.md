# 笔记：线性模型

## 回归 vs 分类

**线性回归**预测连续值，假设关系是特征的线性组合加偏置：`y = Xw + b`。损失用均方误差（MSE），衡量预测与真值的平方距离。

**Softmax 回归**（多类逻辑回归）预测类别概率。先算 logits `z = XW + b`，再经 softmax 转为概率分布。损失用交叉熵，衡量预测分布与真实 one-hot 标签的差异。

两者共享「线性变换 + 损失函数 + 梯度下降」的训练范式，区别在输出空间和损失选择。

## 解析解 vs 梯度下降

线性回归有闭式解（正规方程）：

\[
\hat{\theta} = (X^T X)^{-1} X^T y
\]

实现上常用增广矩阵 \([X \mid \mathbf{1}]\) 把偏置并入 \(\theta\)，用 `lstsq` 求解。当特征数不大时，解析解精确且快速。梯度下降是迭代近似，但在大数据或在线场景更实用，且能推广到无闭式解的分类问题。

MSE 对参数的梯度（全批量，\(n\) 个样本）：

\[
\nabla_w L = \frac{2}{n} X^T (\hat{y} - y), \quad \nabla_b L = \frac{2}{n} \sum_i (\hat{y}_i - y_i)
\]

## Softmax 数值稳定

直接计算 `exp(z_i) / sum(exp(z_j))` 在 `z` 很大时会溢出。标准做法是减去最大值：

\[
\text{softmax}(z_i) = \frac{e^{z_i - \max(z)}}{\sum_j e^{z_j - \max(z)}}
\]

减常数不改变结果（分子分母同乘 \(e^{-\max z}\)），但把指数 argument 压到安全范围。

## 梯度推导要点

- MSE 对 `w` 的梯度：`(2/n) X^T (y_pred - y)`
- 交叉熵 + softmax 组合后，对 logits 的梯度简化为 `(probs - one_hot) / n`

这个简洁形式是 softmax 回归实现的核心。直觉：预测概率高于真类则压低该 logit，低于真类则抬高。

## 偏差-方差与过拟合

线性模型容量有限，在高维小样本上仍可能过拟合。早期信号：训练 loss 持续下降但验证 loss 上升。本模块用合成数据，主要观察学习率对收敛的影响。

## 常见踩坑

1. **学习率过大**：MSE 二次曲面虽光滑，\(\eta\) 过大仍会振荡或发散（见 `optimization_sweep.py` 中 lr=1.0）
2. **忘记特征缩放**：不同量纲的特征会让同一 \(\eta\) 对某些维度步长过大；合成数据已较规整，真实数据常需标准化
3. **softmax 未减 max**：大 logits 导致 `exp` 溢出，得到 `nan` 概率
4. **交叉熵里 `log(0)`**：对概率加 `1e-12` 等小常数防止 `-inf`，但根本办法是稳定 softmax
5. **解析解与 GD 对比时 epoch 不够**：GD 需足够迭代才逼近闭式解；本仓库默认 300 epoch、lr=0.1 可对齐
